AP는 사실상 0이다. 실제 pose 품질을 판단하려면 더 높은 해상도와 충분한 학습이 필요하다.
모든 bbox/pose output weight의 유한 변화가 기록됐으며, 별도 gradient 테스트로
선택된 positive의 Main/AUX bbox/pose/confidence branch에 gradient가 전달됨을 확인했다.
weight 변화만으로 모든 scale에 positive supervision이 있었다고 주장하지 않는다.

학습 checkpoint를 재로딩한 실제 validation 이미지 `000000002685.jpg` 추론에서는
threshold 0.01, max_bbox 5로 5개 인스턴스와 각 17개 keypoint를 JSON/JPEG에 저장했다.
낮은 threshold는 데이터 흐름을 확인하기 위한 것이며, 저장된 skeleton의 정확도를 보증하지 않는다.

별도 소형 CLI 학습에서는 기본 Rich 진행 표시 및 EMA on을 실행했다.
`weight=false` named-run resume로 epoch 0/global_step 3 checkpoint에서 이어서
마지막 epoch 1/global_step 6 checkpoint를 확인했고 quiet result.log도 생성됐다.

## Export와 회귀 테스트

학습 checkpoint의 ONNX 출력은 `[1,336,2258]`, 내부 tensor/initializer 최대 rank는 4다.
ONNX Runtime 1.30.0에서 관측한 PyTorch와의 최대 절대 차이:

| 입력 | 확률 | bbox pixel | keypoint pixel |
|---|---:|---:|---:|
| 실제 validation 이미지 | 2.09e-7 | 4.58e-5 | 2.67e-5 |
| 합성 linear ramp | 2.13e-4 | 0.0325 | 0.2980 |

합성 ramp는 최초 `atol=rtol=1e-4` 비교를 통과하지 못했다. 차이를 숨기지 않고
확률 및 최종 좌표 오차를 따로 기록했으며 두 입력 모두 확률 오차 <1e-3, 좌표 오차 <1 pixel이다.
작은 무작위 모델의 별도 export tests는 기존 `1e-4` 기준으로 static/dynamic batch 및 decoded/probability
두 계약을 ONNX Runtime에서 검증한다.
