# Pose OKS loss 및 증강 검증 (2026-10-31)

이번 검증은 새 학습 경로의 실행·수치·호환성을 확인한다. 기존 recipe 대비 pose AP 향상이나
새 loss 계수의 최적성을 검증한 비교 실험은 아니다.

## 회귀 테스트

```bash
OMP_NUM_THREADS=4 MKL_NUM_THREADS=4 .venv/bin/python -m pytest \
  tests/test_tools/test_pose*.py tests/test_model/test_pose*.py \
  tests/test_model/test_v9_sr_pose.py tests/test_utils/test_pose*.py \
  tests/test_tools/test_loss_functions.py \
  tests/test_tools/test_loss_performance_equivalence.py \
  tests/test_tools/test_nms_free_loss.py -q
```

결과: **206 passed, 5 skipped**, 144.32초. 건너뛴 5개는 `litert_torch` 및
`ai_edge_litert` 미설치로 실행하지 못한 TFLite runtime 테스트다.

- 공식 `COCOeval.computeOks`와 loss 수치 일치, area·sigma별 민감도.
- stride에 따른 기대 좌표, stretch 및 정수 letterbox의 정확한 OKS 역변환.
- TAL 가중치와 gradient, auxiliary head, v0/v1/v2, 빈 target, BF16 처리.
- affine 픽셀·bbox·관절 정렬, crop, area 전달, 두 worker의 seed 재현성.
- 기존 pose checkpoint, 추론 CLI, COCO 평가, ONNX Runtime 및 graph rank 계약.
- 기존 검출·NMS-free loss 회귀.

제한 실행 환경에서는 worker IPC socket 권한 오류가 발생해, 동일한 회귀 테스트를
일반 로컬 실행 환경에서 수행했다. 테스트를 건너뛰거나 assertion을 완화하지 않았다.

## 실제 COCO 학습 smoke

```bash
OMP_NUM_THREADS=4 MKL_NUM_THREADS=4 .venv/bin/python scripts/smoke_pose.py \
  --output runs/pose-oks-smoke-20261031 --workers 0
```

YOLOv9-T pose, CPU float32, 128×128, batch 16, seed 10, random initialization,
EMA off, train 5,915장 / validation 250장, 1 epoch를 사용한다.
새 기본 증강과 `PoseOKSLoss=7.5`, `PoseDFLoss=1.0`, `PoseVisibilityLoss=1.0`을 적용한다.
산출물은 해당 run의 `config.yaml`, `subset_manifest.json`, `report.json`,
`pose-smoke.pt`, `checkpoints/`에 저장한다.

결과: **370 optimizer step 완료**, 346.83초. 전체 batch loss는 272.17–578.34로
모두 유한했고, main/aux 각 scale의 bbox·pose·visibility 출력 weight 갱신을 확인했다.
epoch 로그의 가중 loss는 OKS 8.57996, pose DFL 5.14352, visibility 0.83853이며
out-of-range fraction은 0이었다. 이 로그에는 auxiliary head 가중치도 포함된다.
공식 COCO evaluator가 완료됐고 subset pose AP는 `6.86034e-7`이었다.
random 초기화·저해상도·1 epoch 결과이므로 정확도 개선의 근거로 해석하지 않는다.

## 성능 비교 시 후속 검증

동일 초기 weight·데이터·해상도·학습 길이·seed에서 기존 recipe, 증강만, OKS/TAL만,
전체 변경을 비교해야 원인을 분리할 수 있다. COCO pose AP/AP75/AP-medium과 함께
각 loss 및 out-of-range 비율을 기록한다. crop의 area는 변환된 전체 인스턴스 면적을
유지하는 근사이며, 상세 수식과 설정은 `IMPLEMENTATION_KO.md`에 설명했다.
